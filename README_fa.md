# صفحه شروع مونوگاتاری

صفحه شروع سفارشی با تم شخصیت‌های مجموعه مونوگاتاری، قابل استفاده به عنوان افزونه مرورگر یا صفحه HTML مستقل. شامل ۱۲ تم شخصیت، پشتیبانی آفلاین، آب و هوا، جستجو و میانبرهای قابل تنظیم.

## امکانات

- **۱۲ تم شخصیت** -- هانکاوا، شینوبو، تسوکیهی، کارن، مایوی، کانبارو، سوداچی، اوگی، هیتاگی، نادکو، اونونوکی، هانکاوای سیاه
- **آب و هوا** -- دما و آیکون آب و هوا با [Open-Meteo](https://open-meteo.com/) (بدون نیاز به کلید API، پیش‌فرض: تهران)
- **جستجو** -- گوگل، داک‌داک‌گو، بینگ، بریو، یاندکس
- **میانبرهای قابل تنظیم** -- اضافه، حذف و مرتب‌سازی بوکمارک‌ها با بیش از ۳۰ آیکون SVG
- **لیست کارها** -- مدیریت وظایف با چک‌باکس، ذخیره در localStorage
- **ساعت و تقویم** -- فرمت ۱۲/۲۴ ساعته، تقویم میلادی یا جلالی
- **زبان** -- رابط کاربری انگلیسی و فارسی
- **CSS سفارشی** -- تزریق استایل‌های دلخواه از تنظیمات
- **پشتیبانی آفلاین** -- سرویس‌ورکر تمام منابع را کش می‌کند، بدون اینترنت کار می‌کند (به جز آب و هوا)
- **حالت تاریک/روشن** -- تغییر خودکار (روز/شب) یا دستی برای هر تم

## نصب

### مرورگرهای کرومی (Opera GX, Chrome, Edge, Brave, Vivaldi)

1. این مخزن را دانلود و در یک پوشه دائمی اکسترact کنید
2. به `chrome://extensions` (یا `opera://extensions`, `edge://extensions`) بروید
3. **Developer mode** را فعال کنید
4. **Load unpacked** را بزنید و پوشه پروژه را انتخاب کنید

### فایرفاکس

1. به `about:config` بروید و تنظیم کنید:
   - `extensions.experiments.enabled` = `true`
   - `xpinstall.signatures.required` = `false`
2. فایل‌ها را زیپ کرده، نام را به `.xpi` تغییر دهید و به فایرفاکس بکشید

## تنظیم به عنوان صفحه شروع

### صفحه شروع (کرومی)

1. فایل تم مورد نظر را در مرورگر باز کنید
2. آدرس کامل نوار آدرس را کپی کنید (مثلاً `file:///C:/Users/shoma/Desktop/KHP/themes/karen.html`)
3. به تنظیمات مرورگر -- On startup -- Open a specific page بروید
4. آدرس را جایگذاری کنید

### دکمه خانه (کرومی)

1. به تنظیمات مرورگر -- Appearance -- Show home button بروید (فعال کنید)
2. آدرس تم را در فیلد URL سفارشی وارد کنید

### فایرفاکس

1. به Settings -- Home بروید
2. در بخش "Homepage and new windows"، گزینه "Custom URLs" را انتخاب کنید
3. آدرس تم را جایگذاری کنید

## نحوه استفاده

| عمل | روش |
|---|---|
| تغییر تم | Settings -- THEME CONFIGURATION -- انتخاب شخصیت |
| اضافه کردن میانبر | Settings -- LINKS & SHORTCUTS -- پر کردن برچسب، آدرس و آیکون |
| تغییر مکان آب و هوا | Settings -- IDENTITY & LOCATION -- وارد کردن عرض و طول جغرافیایی |
| تغییر موتور جستجو | Settings -- IDENTITY & LOCATION -- انتخاب موتور |
| تغییر فرمت ساعت | Settings -- IDENTITY & LOCATION -- ۲۴ ساعته یا ۱۲ ساعته |
| تغییر تقویم | Settings -- IDENTITY & LOCATION -- میلادی یا جلالی |
| تغییر زبان | Settings -- IDENTITY & LOCATION -- انگلیسی یا فارسی |
| اضافه کردن کار | Settings -- TODO LIST -- تایپ وظایف، علامت زدن هنگام اتمام |
| تزریق CSS | Settings -- Custom CSS -- نوشتن استایل‌های دلخواه |

## مدیریت کش

کش سرویس‌ورکر پس از بستن مرورگر باقی می‌ماند.

- مشاهده کش: F12 -- Application -- Cache Storage -- `monogatari-cache-v1`
- پاک کردن کش: فایل `cache-info.html` را باز کنید یا در کنسول اجرا کنید:
  ```js
  caches.delete('monogatari-cache-v1')
  ```

## ساختار پروژه

```
KHP/
  index.html              نقطه ورود (هدایت به تم)
  manifest.json           منیفیست افزونه نسخه ۳
  sw.js                   سرویس‌ورکر
  base.css                استایل‌های پایه
  cache-info.html         ابزار مدیریت کش
  js/
    core.js               منطق اصلی، آب و هوا، ساعت، جستجو، میانبرها
    settings.js           رابط کاربری و ذخیره‌سازی تنظیمات
    index.js              هدایت‌کننده تم
    theme-init.js         مقداردهی اولیه تم (قبل از DOM)
    hanekawa.js           چرخش تصاویر هانکاوا
    shinobu.js            چرخش تصاویر شینوبو
  themes/                 فایل‌های HTML همه ۱۲ تم
  assets/
    images/               تصاویر شخصیت‌ها
    videos/               ویدیوهای پس‌زمینه شخصیت‌ها
```

## عیب‌یابی سریع

| مشکل | راه حل |
|---|---|
| تصاویر نمایش داده نمی‌شوند | تصاویر را به `assets/images/` منتقل کنید، نام فایل‌ها را بررسی کنید |
| آب و هوا نمی‌آید | مختصات را در تنظیمات بررسی کنید (پیش‌فرض: تهران 35.6892, 51.3890) |
| تم عوض نمی‌شود | کش مرورگر را پاک کنید و ریلود کنید |
| جستجو کار نمی‌کند | تنظیمات موتور جستجو را بررسی کنید |
